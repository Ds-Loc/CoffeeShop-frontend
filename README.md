# Front-end Dự án Các công nghệ lập trình hiện đại

Ứng dụng CoffeeShop được xây dựng cho đồ án môn học.

## 🛠 Bộ công nghệ (Tech Stack)
- **Framework/Library:** React 19
- **Build Tool:** Vite
- **Routing:** TanStack Router (File-based Routing)
- **Data Fetching / State Management:** TanStack Query (React Query)
- **Language:** TypeScript



## 🚀 Hướng dẫn cài đặt & Chạy local

```bash
# Cài đặt dependency
npm install

# Chạy ứng dụng môi trường dev
npm run dev

2. Sao chép nội dung từ file `.env.example` sang `.env`:
